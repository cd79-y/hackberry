# HACKberry 義手開発ロードマップ

このForkでは、HACKberry本家をベースに、段階的に筋電制御・接触センシング・触覚フィードバックへ拡張します。

## Phase 1 — 本家HACKberryを再現
- BOM（必要部品）を確認
- 3Dプリント部品を準備
- 電装・制御基板を準備
- 組立
- 基本開閉動作を確認

**完了条件**
- 手動入力で安定して開閉できる
- 50回程度の連続開閉で明確な干渉や故障がない

## Phase 2 — 筋電（EMG）入力
- EMGセンサを選定
- 生波形を取得・保存
- 安静 / 筋収縮を判別
- 閾値処理で義手の開閉へ接続

## Phase 3 — 接触センシング
- 指先 / 掌のセンサ方式を検討
- 接触・圧力を取得
- 把持状態をログ化

## Phase 4 — 触覚フィードバック
- 接触情報を身体側へ返す方式を選定
- 振動 / 電気刺激 / その他方式を比較
- 強度・遅延・識別性を評価

## Phase 5 — XR / VR連携（将来）
- 義手状態をPCへ送信
- Unity等で可視化
- 仮想物体との接触情報を義手側へ返す双方向実験

## 開発方針
1. まず本家を動かす
2. 一度に複数箇所を改造しない
3. 実験ごとに条件と結果を記録する
4. 本家由来ファイルのライセンス・著作表示を維持する
5. 医療機器としての使用を前提とせず、研究・試作として扱う
